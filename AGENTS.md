# Teaching workspace

This is a learning repository, separate from the Kyo framework checkout.

For teaching, lesson preparation, exercise review, or course continuation, read [.agents/skills/kyo-teacher/SKILL.md](.agents/skills/kyo-teacher/SKILL.md), then the course progress and teacher notes it names. Follow the learner's latest instructions.

Use the pinned JVM build. Do not modify a sibling Kyo checkout as part of teaching. Investigate module documentation and source incrementally, only for the current lesson and its immediate prerequisites. No module deep dive is authorized during the initial workspace setup.

Preserve learner attempts. Do not fill in exercises while preparing a lesson or reviewing an attempt unless asked. Treat reference solutions as spoilers and keep their classpaths separate.

Keep public course records limited to learning activity. Do not publish credentials, private conversations, personal details, or machine-specific paths. A request to teach does not itself authorize publishing subsequent changes.

Verify new examples, exercise starter compilation, and reference solutions. Record actual commands and outcomes. Ordinary unfinished exercises may intentionally fail assertions; document that expected state and keep them out of root verification. Do not weaken acceptance tests to make an answer pass.

Use plain language and precise types. Do not use em dashes or en dashes. Improve the skill when actual teaching reveals a useful correction.
